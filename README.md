# ReThink — Knowledge Base / "Jarvis"

Vault Obsidian-compatibile + repo Git. È il secondo cervello operativo di ReThink:
si apre con Obsidian per leggere/scrivere, e con Claude Code per interrogarlo,
aggiornarlo e automatizzarlo (vedi `CLAUDE.md`).

## Struttura

- `00-inbox/` — note veloci non ancora smistate. Va svuotata regolarmente.
- `10-strategia/` — brief aziendale, decisioni, validazione. Una nota = una decisione o un dato.
- `20-clienti/` — una cartella per cliente (o prospect). Parti da `_template/`.
- `30-strumenti/` — studio delle piattaforme (Lety.ai, GHL/Squadd, n8n...): cosa fanno, prezzi, limiti trovati.
- `40-moduli-mcp/` — pain point ricorrenti e moduli custom. Regola: 2+ clienti con lo stesso problema → diventa modulo.

## Regole

1. Tutto in Markdown, tutto committato. Niente strategia che vive solo in chat.
2. Ogni conversazione con un potenziale cliente diventa una nota in `20-clienti/` lo stesso giorno.
3. Le decisioni si scrivono in `10-strategia/decisioni.md` con data e motivazione.
