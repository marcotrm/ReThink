# Istruzioni per Claude Code — vault ReThink

Questo repo è il knowledge base ("Jarvis") di ReThink, un'azienda in fase di validazione:
agenzia AI per PMI/professionisti italiani su infrastruttura affittata (Lety.ai / GoHighLevel),
con moduli MCP custom quando le piattaforme non bastano. Il brief completo è in
`10-strategia/company-brief.md` — leggilo prima di rispondere a domande strategiche.

## Come lavorare in questo vault

- È un vault Obsidian: Markdown puro, link interni `[[nome-nota]]`, niente HTML.
- Nuove note su un cliente → `20-clienti/<nome-cliente>/`, partendo da `20-clienti/_template/`.
- Nuove note su uno strumento → `30-strumenti/<strumento>.md`.
- Ogni decisione presa va aggiunta a `10-strategia/decisioni.md` con data (YYYY-MM-DD) e motivazione.
- Quando l'utente racconta una conversazione con un cliente/prospect, trasformala in nota strutturata:
  chi, settore, pain point, budget indicativo, prossimo passo.
- Se lo stesso pain point compare in 2+ clienti diversi, segnalalo e proponi una scheda in `40-moduli-mcp/`.

## Ruolo

Sii critico, non compiacente: se una nota strategica non è supportata da dati di validazione
(clienti reali, cifre, conversazioni), dillo esplicitamente.
